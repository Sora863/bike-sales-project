# 🚴‍♂️ Bike Sales Dashboard – Excel Project

This project is an interactive Excel dashboard that analyzes bike sales data using pivot tables, slicers, and data visualization tools. It serves as a showcase of my skills in Excel data analysis and dashboard design.

## 📊 Project Overview

- Tool: **Microsoft Excel**
- Purpose: To analyze and visualize bike sales trends
- Key Features:
  - Interactive slicers (e.g., region, customer segment)
  - Dynamic pivot charts
  - Clean dashboard layout
  - Filterable data insights

## 🔍 What I Did

- Cleaned and structured the dataset
- Built pivot tables for key metrics (sales by region, category, customer type)
- Created dynamic visualizations using Excel's built-in chart tools
- Integrated slicers for user-driven filtering
- Designed a dashboard that’s both insightful and user-friendly

## 🧠 Skills Demonstrated

- Data cleaning and transformation
- Pivot table and pivot chart creation
- Dashboard design in Excel
- Analytical storytelling
